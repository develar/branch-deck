Add connection retry logic

The pool gave up after the first failed connection attempt, so a short database restart surfaced as an error for every request that was in flight at that moment.

Retry the connection instead:

  • wait with exponential backoff, starting at 100 ms and capped at 5 s, for up to 6 attempts
  • retry only transient errors (connection refused or reset)
  • log every retry at debug level

The limits can be tuned in the pool configuration: 

    
      retry: { attempts: 6, maxDelayMs: 5000 }
