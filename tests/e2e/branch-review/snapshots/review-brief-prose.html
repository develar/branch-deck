    Storage

    The window keeps its layout in a file of the IDE in the config directory, not in the project, so a checkout of another branch never changes it. The file holds the tool windows of each project: their side, their size and , their order and the tool window in focus . It is written when the window closes, and read once when it opens. A file that cannot be read is renamed aside, and the window opens with the default layout.

    The store keeps at most 500 projects. A write above the bound drops the layouts of the projects with the oldest open that pin no tool window .

    Added: The focus of a tool window is a fact the window derives from the last click. owns its rules.
