Configure the branch prefix

The branch prefix is the first part of the names of your virtual branches. A personal prefix, like your username, keeps your branches apart in a shared repository.

In Branch Deck

Settings → General, Branches. It applies to every repository without a prefix of its own, takes precedence over the global Git setting below, and the Agent CLI (bd) uses it too.

In Git, for all repositories

Run in a terminal, with your name or initials: 

            git config --global branchdeck.branchPrefix your-name

How it works

Branch Deck groups commits based on message patterns:

  • Explicit prefix: (auth) Add login form → john/virtual/auth
  • Issue key: ABC-123 Fix login bug → john/virtual/ABC-123
  • With subsystem: [threading] ABC-123 Fix login bug → john/virtual/ABC-123

An explicit prefix takes precedence over an issue key. virtual always follows the branch prefix.

For one repository

Settings → Repository, Branch prefix: saved as branchdeck.branchPrefix in the .git/config of the repository, where bd reads it too. It takes precedence over the prefix of Branch Deck.
