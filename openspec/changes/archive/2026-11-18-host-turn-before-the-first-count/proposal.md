# Proposal

## Why

Right after the upgrade to the turn by cores, while only the holder of the build before held the turn and no run of
the new build had counted the cores of the host, `brd-host runs studio` said `heavy turn: 0.0 of 0 cores held`.

## What Changes

- The head line says `heavy turn: <n> run(s) hold the whole host; no run of this build counted its cores yet` then.
