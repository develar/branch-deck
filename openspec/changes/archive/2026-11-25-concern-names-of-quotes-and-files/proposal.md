# Proposal

## Why

Of the 43 concerns of jps-bridge, several were named by a word no reader takes for a task (`simple`, `composition`,
`four`, `does`, `outputs`, `mechanisms`): the words of the sentences the code spans of Markdown quote, the headings an
OpenSpec delta quotes (`- FROM: `### Requirement: …``) and the titles of tests its links to tests name, counted as
names of code. Another, "Root", was the 35 `BUILD.bazel` of a repeated edit, named by the root they share.

## What Changes

- Of a code span of prose that quotes a sentence (a span with a space) only its compound names count, as of a sentence
  a config or a literal quotes.
- A concern of files of one name in several directories, no token, declaration or one file naming it, is named by that
  name (`files`, "BUILD.bazel"), not by the directory they share. `"schema": 43`.

Capabilities: `branch/review-concerns`, `branch/review-plan`, `branch/review-units`, `review/range-reading`.
